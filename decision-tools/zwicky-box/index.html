Zwicky box

Combine the parameters of a problem to generate options you’d never brainstorm.

Contents

Overview

The Zwicky box (morphological analysis) breaks a problem into its independent parameters, lists the possible values for each, and then systematically combines them. Where brainstorming drifts toward familiar answers, the box mechanically produces combinations no one would think to propose — including strange ones that turn out brilliant.

Its power is combinatorial coverage. Three parameters with four values each yield sixty-four combinations; the box guarantees you consider the whole space rather than the handful your imagination volunteers.

When to use it

You need genuinely novel solutions and freeform brainstorming keeps circling the obvious.

How to use it

Step 1

Break the problem into parameters

Identify the independent dimensions of the solution — the things that can vary.

Step 2

List values for each

Under every parameter, list the possible options.

Step 3

Build the grid

Arrange parameters as columns and values as rows — the box.

Step 4

Combine across columns

Pick one value from each parameter to form a candidate solution; sweep systematically.

Step 5

Evaluate the interesting combinations

Most combinations are duds; a few are novel and viable. Those are the payoff.

Worked example

A team designing a new snack sets parameters: format (bar, bite, drink), base (nut, fruit, grain), flavour (savoury, sweet, spicy), occasion (breakfast, gym, desk). Sweeping combinations surfaces ‘savoury grain bite for the desk’ — a niche nobody had brainstormed — which becomes the winning product. The grid found what free association missed.

Common pitfalls

  • Choosing parameters that overlap instead of being independent.
  • Being overwhelmed by the combinations — filter to the promising few quickly.
  • Using it for simple problems where brainstorming is faster.

Frequently asked questions

How many parameters should I use?

Three to five. More explodes the grid; fewer misses the novelty.

Do I evaluate every combination?

No — sweep for the ones that are novel and plausible, and ignore the obvious duds.

Why does it beat brainstorming?

Brainstorming samples the space unevenly toward the familiar; the box covers it systematically.
